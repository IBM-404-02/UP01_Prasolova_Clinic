# УП.01.01 — Система управления медицинской клиникой
Прасолова ЕА 4ИСИП-423

WPF-приложение (.NET Framework, C#) для учёта медицинских услуг, оказанных пациентам клиники.
База данных — Microsoft SQL Server, доступ к данным — ADO.NET Entity Framework (Database First).

## Функции
- Авторизация с разграничением ролей (Пользователь, Администратор)
- Капча после трёх неверных попыток входа
- Регистрация с проверкой данных, хэширование паролей (SHA-1)
- Смена пароля
- Пользователь: просмотр своих услуг, поиск, фильтрация по типу, сортировка
- Администратор: просмотр всех услуг, поиск, фильтрация, сортировка, добавление, редактирование, удаление
- Диаграмма расходов пациента по типам услуг (5 видов диаграмм)
- Экспорт отчётов в Microsoft Word (.docx), PDF и Microsoft Excel (.xlsx)
- Два стиля оформления с сохранением выбора пользователя

## Структура решения
- `db/schema.sql` — скрипт создания и заполнения базы данных
- `res/` — ресурсы приложения (иконка, шрифт Open Sans)
- `Pages/` — страницы приложения
- `Core.cs` — общие методы: контекст БД, аутентификация, хэширование, сообщения
- `Dictionary.xaml`, `GreenTheme.xaml` — словари стилей
- `MessageFilter.cs` — повтор вызовов Office при занятости приложения

## Запуск
1. Выполнить `db/schema.sql` в SQL Server Management Studio.
2. При необходимости изменить имя сервера в строке подключения в `App.config`.
3. Открыть `UP01_Prasolova_Clinic.sln` в Visual Studio 2022 и запустить (F5).
